Paradex SOL default profile
===========================

Default SOL Paradex profile now points to the tuned 25 bps configuration with tighter inventory controls.

Primary tuned config
- configs/paradex_sol_avellaneda_25bps_recommended_tuned.yaml

Default SOL alias

Why
- keeps the validated reduce-only shutdown flatten fix
- lowers base size and configured inventory cap
